프로젝트의 기초 룰입니다.

* 협업은 깃허브로 진행합니다. Github desktop 설치하셔서, 제가 초대한 레포지토리 클론 후 작업 하시면 됩니다.

1. 깃허브
- 절대 main 브랜치에서 직접 작업하지 않고, 본인 이름의 branch에서 작업합니다.
- 본인 브랜치 내에서 커밋 / 푸시는 자유입니다.
- 모든 작업이 완료되면 pull request를 보냅니다. 절대 main 브랜치에 직접 merge(병합) 하지 않습니다. 검토 후 병합합니다.
- main 브랜치에 푸시 있다고 하면, 본인 브랜치에 merge(병합)하여 변경 사항을 받아온 뒤 작업해야 합니다. 항상 작업 전 main 브랜치에 변경사항 있는지 확인 하고 merge한 후 작업합니다.

2. 프로젝트 파일 관리
 - index.html, main.css, main.js는 초기 스타일, 메인 화면만 작성하며, 본인 페이지의 css와 js는 상위 css, js 파일 안쪽 '본인 html 파일 이름' 하위에 만드시면 됩니다. 몇 개를 만드시던 괜찮습니다.
- 같은 header, footer 스타일을 위해 본인 파일에 index.html를 복사하여 메인 섹션을 새로 작성합니다.
- index.html 내에 수정해야 할 사항(a 태그 링크 연결 등)은 모든 페이지 완성 후 수정하며, 이외 사항들은 팀장에게 직접 알립니다.
